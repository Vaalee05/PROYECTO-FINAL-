# Ciclo 4 - Versión Final y Presentación Visual

## Descripción

En este ciclo se realizó la entrega final de DOPOSoccer, completando la transición del videojuego a una versión visual y ejecutable fuera de BlueJ. Se integraron las funcionalidades desarrolladas durante los ciclos anteriores con una interfaz gráfica que permite configurar partidas, seleccionar personajes y jugar de manera interactiva.

También se realizaron ajustes en la organización del proyecto, la persistencia de información y la presentación visual del videojuego.

## Funcionalidades finales

- Interfaz gráfica para iniciar y configurar partidas.
- Modalidades Jugador vs. Jugador y Jugador vs. Máquina.
- Selección de personajes y perfiles de máquina.
- Partidas por tiempo y por cantidad de goles.
- Movimiento, salto y patadas de los personajes.
- Poderes especiales y efectos visuales.
- Sistema de vida, estadísticas y progreso de los jugadores.
- Guardar y abrir partidas.
- Pausar y reanudar los partidos.
- Marcador e información de los jugadores durante el juego.
- Manejo de excepciones y registro de errores.

## Interfaz gráfica

Se desarrolló la presentación visual utilizando Java Swing, incorporando ventanas para el menú principal, la selección de personajes y el desarrollo de los partidos.

La interfaz permite interactuar con las funcionalidades del juego y visualizar elementos como la cancha, los personajes, el balón, el marcador y los estados de los jugadores.

## Organización y ejecución

Se preparó el proyecto para ejecutarse desde Visual Studio Code, conservando la separación entre el paquete `juego` y el paquete `interfaz`.

También se incorporó un punto de entrada para iniciar la aplicación y archivos de configuración para facilitar su compilación y ejecución.

## Resultado del ciclo

Al finalizar esta etapa se obtuvo una versión visual e integrada de DOPOSoccer, que reúne las funcionalidades desarrolladas durante el semestre y permite jugar partidas mediante una interfaz gráfica, conservando la lógica y las características principales del proyecto.
