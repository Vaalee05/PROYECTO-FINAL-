# Ciclo 2 - Persistencia y Dominio

## Descripción

En este ciclo se continuó con el desarrollo de DOPOSoccer, ampliando las funcionalidades de la primera versión e incorporando la persistencia de partidas y la modalidad Jugador vs. Máquina.

## Objetivos

- Implementar la opción de guardar partidas.
- Permitir abrir partidas guardadas.
- Desarrollar la modalidad Jugador vs. Máquina.
- Ampliar y mejorar el dominio del juego.
- Planificar las siguientes versiones del proyecto.

## Entregables

- Código fuente actualizado.
- Diagramas de clases en Astah.
- Documento de retrospectiva.
- Planificación de las versiones del proyecto.

## Resultado del ciclo

Se avanzó en la ampliación de DOPOSoccer, trabajando en la persistencia y las nuevas funcionalidades del dominio para continuar con el desarrollo del videojuego.
