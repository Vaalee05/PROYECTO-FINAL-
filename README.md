# Desarrollo Orientado por Objetos - Proyecto Final

## Descripción

Este repositorio contiene el desarrollo del proyecto final **DOPOSoccer**, realizado para la asignatura Desarrollo Orientado por Objetos (DOPO).

El proyecto consiste en desarrollar un videojuego de fútbol arcade en 2D inspirado en Head Soccer. Los jugadores controlan personajes de diferentes países y compiten utilizando movimientos, saltos, patadas y poderes especiales.

El desarrollo se organizó en cuatro ciclos incrementales, en los que se implementaron las funcionalidades del juego, se amplió el dominio, se incorporó persistencia, se desarrolló la modalidad Jugador vs. Máquina y finalmente se integró una interfaz gráfica para ejecutar el videojuego.

## Ciclos del proyecto

### Ciclo 1 - Presentación y Dominio

Se desarrolló la estructura inicial de DOPOSoccer, implementando las clases principales del dominio y las mecánicas básicas del partido.

Se incorporó la modalidad Jugador vs. Jugador, la selección de personajes, los movimientos, las patadas, los poderes especiales y una primera interfaz gráfica funcional.

### Ciclo 2 - Persistencia y Dominio

Se amplió el proyecto mediante la incorporación de mecanismos para guardar y abrir partidas. También se trabajó en la evolución del dominio y en la planificación de las siguientes versiones.

### Ciclo 3 - Persistencia e Inteligencia Artificial

Se continuó con el desarrollo de la persistencia y se incorporó la modalidad Jugador vs. Máquina, incluyendo diferentes perfiles de comportamiento para el oponente controlado por el computador.

También se avanzó en el sistema de progreso, las estadísticas de los jugadores y el manejo de errores.

### Ciclo 4 - Entrega Final

Se completó la integración del proyecto y su transición a una versión visual ejecutable desde Visual Studio Code.

Se consolidaron las funcionalidades desarrolladas durante los ciclos anteriores y se preparó el proyecto para su ejecución mediante una interfaz gráfica desarrollada con Java Swing.

## Tecnologías y herramientas utilizadas

- **Java:** implementación de la lógica y las funcionalidades del videojuego.
- **Java Swing:** desarrollo de la interfaz gráfica.
- **BlueJ:** desarrollo inicial y ejecución del proyecto.
- **Visual Studio Code:** configuración y ejecución de la versión visual.
- **Astah:** elaboración de diagramas de clases y diseño.
- **JUnit 5:** desarrollo y ejecución de pruebas automatizadas.
- **Maven:** administración de dependencias y ejecución de pruebas.
- **Git y GitHub:** control de versiones y organización de las entregas.

## Pruebas y documentación

Durante el desarrollo se realizaron pruebas unitarias, de integración y de aceptación para verificar el comportamiento de las funcionalidades implementadas.

El repositorio también contiene diagramas de diseño, documentos de retrospectiva y archivos de código correspondientes a las diferentes etapas del proyecto.
